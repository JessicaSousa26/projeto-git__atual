# Painel de Usuários — Bootstrap + APIs

Projeto exemplo dividido em pastas (como no exercício), consumindo a API pública **ReqRes** e usando **Bootstrap 5** + **Fetch API**.

## Estrutura
```
painel-usuarios-bootstrap-api/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── app.js
└── assets/
    └── (imagens opcionais)
```

## Como executar
1. Baixe o `.zip` e extraia.
2. Abra o `index.html` no navegador (duplo clique).
3. Clique em **Carregar da API** para popular a lista.
4. Cadastre usuários no formulário (validações básicas).
5. Dê **duplo clique** no card para remover.
6. Use **Exportar JSON** para baixar o estado atual.

> Observação: a criação/remoção na API é **simulada** (ReqRes retorna respostas de teste). A lista é mantida no **estado do front-end**.
